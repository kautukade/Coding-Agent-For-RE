Security model

Single-user localhost control plane.

The dashboard and model router listen only on 127.0.0.1. API keys are saved in a current-user-restricted local file and are never returned in full to this UI. OpenCode talks to the localhost router instead of receiving cloud keys directly. Routing activity stores metadata only, not prompt text.
