Security notes

Designed for a single Windows user on the local machine.

The dashboard binds to 127.0.0.1 only. Saved API keys are kept in the local application configuration and are not returned in API responses. The secrets file is restricted to the current Windows user on a best-effort basis. OpenCode receives keys only as environment variables when the agent starts.
